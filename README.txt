Zirui Zhao portfolio

Upload everything in this folder to any static host (Netlify, Vercel, GitHub Pages, your own server) and open index.html.
To preview on your computer, run a local server in this folder, e.g.  npx serve .  or  python3 -m http.server  then visit the address it prints.
(Double-clicking index.html directly may show a blank page because browsers block 3D/modules from file://.)
